# Sample export

**Get your chosen sounds ready for your sampler.**

Turn a reviewed collection into compatible WAV files with short, useful names.
Preview what will be exported, create copies and check them before transfer.
Your source audio stays intact.

[Get started](../docs/GETTING-STARTED.md) · [Export a collection](REFERENCE.md#preview-then-export) ·
[Command reference](REFERENCE.md) · [Architecture](ARCHITECTURE.md)

## From favourites to hardware

- **Catch problems before conversion.** Check the selected files, roles, names
  and configured device limits.
- **Prepare compatible copies.** Apply the device's audio format and folder
  layout without manually converting each sample.
- **Reuse work you can trust.** Skip conversions when saved checks confirm that
  the source, settings and output still match.
- **Transfer the selection you reviewed.** Copy the selected Octatrack or TR-8S
  export to a mounted card, or prepare Digitakt files for Elektron Transfer.

## Supported devices

| Device | How the prepared collection reaches it |
|---|---|
| Octatrack MKII | Copy to a mounted CompactFlash card. |
| Digitakt MKI | Load the prepared files through Elektron Transfer. |
| TR-8S | Copy to a mounted SD card, then import on the instrument. |

Exact formats and limits are in the [export reference](REFERENCE.md#output-formats).

## Preview, then export

Start with [approved favourites](../docs/WORKFLOWS.md#3-curate-by-ear), review the
proposed files and names, then generate the export. The
[export walkthrough](REFERENCE.md#preview-then-export) provides each command
and explains which steps write files.

Converted files are checked in software. Confirm playback, assignment and
save/reload with a [small hardware test](../docs/WORKFLOWS.md#first-device-smoke-test)
before a larger transfer. Automatic collection sizing from available device
space is still planned.
